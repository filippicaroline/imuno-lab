# ImunoLab — versão reconstruída

Plataforma de estudo em imunologia com interface React/Vite, biblioteca dos três PDFs, busca textual por página, flashcards e simulados.

## Banco de estudos
- Imunologia P1: 100 flashcards e 100 questões.
- Imunologia P2: 100 flashcards e 100 questões.
- Imuno-Hemato: 100 flashcards e 100 questões.

Total: 300 flashcards e 300 questões. O banco combina cartões originais com perguntas de recuperação geradas a partir do texto extraído dos PDFs. Recomenda-se revisão editorial das alternativas e explicações antes de uso avaliativo formal.

## Publicação no Vercel
1. Envie o conteúdo desta pasta para um repositório GitHub.
2. Configure o projeto Vercel para usar esse repositório.
3. Build command: `npm run build`; output directory: `dist`.

## Desenvolvimento local
`npm install` e depois `npm run dev`.
